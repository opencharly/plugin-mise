| # | signature | root cause | fix |
|---|---|---|---|
| 1 | `produce.0: conflicting values "aur"/"cargo"/"npm"/"pixi" and "mise"` | `produce:` is typed `[...#BuildType]`, `#BuildType = "pixi" \| "npm" \| "cargo" \| "aur"`. `mise` is not a prebuild format — the mise builder is selected by `external_builder: mise`. | drop the **8** `produce: [mise]` lines |
| 2 (PHANTOM — corrected) | `distro: conflicting values ["alpine:3.24","alpine"] and {[string]:#DistroPackages}` | **NOT an independent bug.** A CUE `empty disjunction` reports a *cascade*: with `produce` invalid, the whole `candy` disjunct fails and every field in it errors. Re-measured after removing only `produce`: `distro: [list]` validates CLEAN **and** the image-build needs it (`box alpine-builder has no distro definition to install curl-tar with`). | **keep `distro:` — no change** (the earlier attempt to remove it was wrong and is reverted in this commit) |
| 3 | `local candy "plugin-mise" shadows remote candy "…/plugin-mise"` | `candy/mise-consumer` `bake_plugin`-ed this plugin by its **own repo's remote ref**; the local candy and that ref share a name → a self-shadow (the sdk emitter's own comment: "the shadow is deliberate and effective"). Fatal only because the ref was also stale. | bake the bare **`plugin-mise`** |
| 4 | (the `#717` symptom) `plugin-mise:v2026.274.0618` stale | the self-ref in #3 | removed by #3 |
| 5 | `check-image`: `mise-module-present` + `mise-schema-present` FAIL | both asserted `/usr/lib/charly/plugins/plugin-mise.providers`, but the bake lands at **`/usr/local/lib/charly/plugins/`** (the generated Containerfile COPYs there — issue #595). Verified in the built image. | point the 2 checks at `/usr/local/lib/…` |
| 6 | R10 bed `image-build` FAIL: `mise ERROR … 404 … https://dl.google.com/go/go1.25.14…` | the R10 `mise-consumer` downloaded Go from `dl.google.com`, which this venue's egress filter 404s for every version (see probes). **Cured in-tree** (this PR touches the file): use a universally-reachable, musl-static tool with the SAME mise builder+verb mechanism. | `mise use go@1.25` → `mise use ripgrep` (+ its `rg --version` check) |

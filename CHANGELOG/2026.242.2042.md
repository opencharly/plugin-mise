## RCA — live failures surfaced and fixed by the fresh bed rebuilds (R1)

1. **alpine: `mise: not found` at the stage install** — NOT a cache issue (reproduced with `--no-cache`): the pinned mise release is a **glibc** build; Alpine is musl, the binary's `/lib64/ld-linux-*` interpreter is absent, exec fails ENOENT → "not found". Fixed upstream in **opencharly/sdk#198** (the stage probes `/lib/ld-musl-*.so.1` and appends `-musl` to the release asset; the version pin is named, `miseVersion`).
2. **debian/ubuntu: task-download failure (`curl: not found`)** — the beds lacked `distro:` declarations, so the bootstrap emitted no apt install of curl; fixed with the distro declarations mirroring charly's own boxes.
3. **fixture: `python@3.12` compiles from source on musl** (no C compiler) — fixed by the libc-agnostic fixture (zig + go), not by compiler chains in the images.
4. **check-image: `mise-schema-present` runtime failure** — check box re-runs baked candy build-context plan checks at runtime, where only the compiled plugin (+ `.providers` manifest) is baked; the checks now verify the real artifact in each context (above).
